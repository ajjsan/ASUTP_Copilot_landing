# ASU TP Copilot

Одностраничный учебный лендинг на React для презентации концепции **ASUTP Copilot** — интеллектуального помощника инженера АСУТП.

Проект показывает, как ИИ-агент может помогать при сопровождении верхнего уровня промышленной автоматизации: систематизировать сведения об инциденте, формировать диагностические гипотезы и показывать рекомендации для дальнейших проверок. Все данные демонстрационные, без подключения к ПЛК, внешним API или реальным ИИ-сервисам.

## Технологии

- React
- Vite
- JavaScript
- CSS
- Lucide React

## Реализовано

- адаптивная шапка с якорной навигацией;
- hero-блок с CSS/React-визуализацией интерфейса мониторинга;
- секции «Проблема», «Возможности», «Как это работает», «Преимущества»;
- демонстрационный интерфейс с выбором одного из трёх инцидентов;
- обновление карточки анализа через `useState`;
- повторяющиеся карточки и шаги из массивов данных через `map`;
- финальный призыв к действию и подвал с программным выводом текущего года.

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить dev-сервер:

```bash
npm run dev
```

Проверить production-сборку:

```bash
npm run build
```

Дополнительно можно запустить линтер:

```bash
npm run lint
```
